## Dos libertades diferentes
**Consulta libre:** cualquier persona puede leer el material que se publique aquí sin autorización individual.

**Participación activa:** para utilizar los mecanismos GitHub Issues y Pull Requests se necesita iniciar sesión en GitHub y cumplir sus normas. Las contribuciones son voluntarias y pueden ser aceptadas, discutidas o rechazadas con justificación.

La consulta pública **no constituye una cesión automática de derechos de reproducción, modificación o explotación comercial**. No hay licencia abierta concedida por el mero hecho de publicar. Una eventual licencia se decidirá expresamente antes de autorizar usos adicionales.

## Límite del acceso público
Este repositorio **no da acceso** al repositorio original privado UNAI–ALM, datos personales, códigos restringidos, archivos históricos reservados o documentación sensible. No debe divulgarse información privada en Issues o Pull Requests.

**No existen contraseñas ni formularios de admisión para leer la parte pública.** Tampoco se exige realizar el curso para consultar el repositorio. El curso es una propuesta de formación previa al trabajo estructurado dentro del programa, no una barrera para la lectura ni para plantear objeciones.

## Ciencia sin certezas anticipadas
Los ejemplos matemáticos clásicos se distinguen de las propuestas originales y de sus obligaciones de prueba. NS3D, Riemann y Hodge permanecen abiertos en esta edición. Ninguna institución se considera colaboradora o avalista sin consentimiento expreso.
