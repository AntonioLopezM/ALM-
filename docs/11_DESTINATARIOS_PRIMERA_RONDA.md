# Primera ronda de invitaciones: 36 destinatarios autorizados

**Fecha de autorización:** 10/11/2026 · **Estado:** propuesta de contacto, NO entidades colaboradoras ni avalistas.

El autor del proyecto ha autorizado considerar a estas **36 entidades** como primera ronda de invitaciones directas, **solo después de confirmar un reconocimiento institucional verificable de ALM**. Sus webs se ofrecen como referencia para localizar los canales de contacto institucionales, no como direcciones ya verificadas de invitación.

**Condición de apertura de cada invitación:** transparencia completa de los objetivos, afirmaciones, resultados, decisiones y atribución de las contribuciones; lo reservado se identifica y protege sin aparentar que sea evidencia públicamente examinada. Si una institución no desea colaborar bajo esta norma, **no es necesario que responda**.

**Toda aportación de mejora en cualquier ámbito será tratada con igual consideración inicial, independientemente de quién la proponga**, aplicando los mismos criterios de mérito, evidencia, reproducibilidad, utilidad y seguridad.

**Prohibido:** deducir adhesiones a partir de esta lista, enviar mensajes antes del hito, utilizar contactos personales privados, hacer envíos duplicados o divulgar material sensible. Si no se identifica un correo de contacto profesional oficial adecuado para alguna entidad, se registra como pendiente y no se fuerza el contacto.
