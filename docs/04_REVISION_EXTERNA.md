# Protocolo de revisión científica externa

La invitación es a criticar enunciados y evidencia, no a respaldar previamente una conclusión.

## Cómo presentar una revisión

Puede abrirse una incidencia o una propuesta de cambio en este repositorio público (si GitHub Issues está habilitado) con:

1. Identificador de sección y cita exacta de la afirmación.
2. Hipótesis y dominio que se están evaluando.
3. Prueba propuesta, contraejemplo, error de cálculo o referencia bibliográfica.
4. Resultado que puede reproducirse y resultado que no.
5. Clasificación sugerida: demostrado / modelo / condicional / conjetura / no evaluado.

## Reglas de respuesta

Las objeciones comprobables se documentan; los resultados negativos se conservan; las correcciones explican el cambio. Un informe de terceros no se presenta como aval institucional sin su autorización. Ninguna respuesta del proyecto debe inferir que la falta de réplica implica aceptación.

## Material reservado

Este repositorio no contiene los paquetes experimentales internos. Las peticiones de auditoría restringida no autorizan su publicación y deberán evaluarse expresamente, con alcance y condiciones definidos. No incluir secretos, datos personales, credenciales, direcciones privadas ni materiales sensibles en incidencias públicas.

**Sin evaluación formal externa acreditada hasta donde documenta esta edición pública.**
